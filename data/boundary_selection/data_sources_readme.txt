*=================================
*Data sources boundary selection 
*=================================

Zoning data - https://zoningatlas.mapc.org/ (MAPC Zoning Atlas)

Roads (EOTMAJROADS_ARC + EOTROADS_ARC) - https://www.mass.gov/info-details/massgis-data-massgis-massdot-roads (MassGIS)

Water (HYDRO100K_ARC) - https://www.mass.gov/info-details/massgis-data-hydrography-1100000 (MassGIS)

School attendance areas - https://nces.ed.gov/programs/edge/sabs (NCES)

School districts - https://www.mass.gov/info-details/massgis-data-public-school-districts (MassGIS)

municipalities - https://www.mass.gov/info-details/massgis-data-municipalities (MassGIS)



Code executed on ArcGIS Pro 3.6.0

All files were compressed for GitHub repo
